# Interior Design Portfolio Frontend

This is the React.js + Tailwind CSS frontend for the Interior Design Portfolio website.

## Features
- Home, About Us, Services/Projects, Moodboard Gallery, Contact pages
- Responsive design
- Framer Motion for animations
- WhatsApp/Instagram integration

## Getting Started
1. Install dependencies: `npm install`
2. Start development server: `npm run dev`

## Deployment
Deploy to Vercel or Netlify for best results.
